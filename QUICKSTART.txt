PI OFFICE · WINDOWS QUICK START

1. Install Node.js 24 LTS from https://nodejs.org/ if needed.
2. Extract the pi-office folder or clone the repository somewhere private.
   For a Git clone, run npm ci and npm run build in that folder first.
3. Double-click START-OFFICE.cmd. Keep its window open.
4. Open http://127.0.0.1:4317 in your browser.
5. Choose Explore demo to look around, or connect a real Pi session:

   Open PowerShell in your project folder and run:
   & 'C:\path\to\pi-office\CONNECT-PI.cmd'

   Replace the path with your extracted app folder. Do this for each
   Pi session you want to see. Pi itself must already be installed.

A release ZIP with prebuilt dist/ does not need npm install to run.
A source/Git checkout needs npm ci and npm run build first.
This is a local, view-only MVP. It never controls your agents.
Close the bridge window / press Ctrl+C to stop the office; Pi keeps working.
